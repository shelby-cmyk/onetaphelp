Cookie Policy

Last Updated: 2026-05-08

This page lists the cookies, local storage, and similar technologies we use on onetaphelp.com. You can change your choices any time using the Cookie Preferences control or in your browser settings. For broader detail on how we handle data, see our Privacy Policy.

What we set today

Name Type Purpose Lifetime Category
oth_cookie_consent localStorage Stores your cookie preferences (essential / analytics / marketing) and version. Until cleared Essential
oth_utm sessionStorage Captures UTM source on the current visit so we can route your call correctly. Session only Essential
oth_first_touch localStorage Records the first marketing channel that brought you to our site (kept for attribution & analytics). Until cleared Analytics
oth_session_touch sessionStorage Latest marketing source for this browsing session. Session only Essential
oth_banner_dismissed sessionStorage Remembers that you closed the promotional banner so it does not reappear in this session. Session only Essential
oth_exit_shown sessionStorage Records that the “before you go” modal has already been shown so it doesn’t repeat. Session only Essential

Tools we may add when you accept analytics or marketing

If you opt in, we may load the following on this site. These vendors set their own cookies; please consult their policies for full details.

Provider Purpose Category
Google Analytics 4 (_ga, _ga_*) Aggregate site usage analytics — pages viewed, scroll depth, conversion paths. Analytics
Meta Pixel (_fbp) Show relevant Facebook/Instagram ads and measure ad performance. Marketing
Google Ads conversion / remarketing (_gcl_*) Measure ad-driven conversions and show remarketing ads. Marketing
CallRail (or similar) Match phone calls to the marketing source that drove them. Essential

Browser controls

Most browsers let you block or delete cookies. Help links: Chrome · Safari · Firefox · Edge.

Browser signals we honor

  • Do Not Track — we treat this as an opt-out of all non-essential tracking and skip the consent banner.
  • Global Privacy Control (GPC) — we treat this as a request to opt out of any “sale” or “share” of personal information under California, Colorado, Connecticut, and similar laws.
